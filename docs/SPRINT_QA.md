# WildBear HQ Sprint QA

Use this checklist for the Daily Focus, Weekly Calendar, and Reminder sprint.

## Before Testing

- Open app in Expo Snack
- Refresh preview
- Confirm no red screen
- Confirm bottom nav is visible

## Daily Focus QA

- [ ] HQ screen loads
- [ ] Top 3 tasks display
- [ ] Highest priority task appears first
- [ ] Open Tasks button works
- [ ] Open Pipeline button works
- [ ] Completing a task updates momentum

## Weekly Calendar QA

- [ ] Weekly focus blocks display
- [ ] Complete block works
- [ ] Reopen block works
- [ ] Weekly progress count updates
- [ ] Calendar does not crowd bottom navigation

## Reminder Cards QA

- [ ] Reminder cards display calmly
- [ ] Reminder complete/dismiss works
- [ ] No native notification prompt appears
- [ ] No external dependency is required

## Regression QA

- [ ] Create tab still works
- [ ] Pipeline tab still works
- [ ] Products tab still works
- [ ] Tasks tab still works
- [ ] Agents tab still works
- [ ] Money tab still works
- [ ] Reset Demo still works

## Pass Criteria

Sprint is healthy when:

- No red screen appears
- Bottom navigation remains usable
- HQ gives a clear next move
- Tasks guide execution
- Calendar supports rhythm
- Reminders reduce drift
